## 提示词怎么写才省
执行 AI 已装 company-dossier 技能时，提示词只写四样：
1. 代码或篮名（篮子写清代码清单）；
2. 批次目录（研究总库 `00 收件箱/<AI名>/<日期>_<范围简称>/`；0.8.1 起成品与 `00_索引` 直接放这一层，图片、历史版本、留痕进 `_底稿/`；0.9.0 起成品一律是 Google 文档与 Google 表格，md、docx、xlsx、csv 不上传，见 SKILL.md D5）；
3. 本次特殊要求（没有就写"无"）；
4. 一句"按 company-dossier 技能 0.9.0 做"。

不复述流程、规则、模板和自检项——技能里都有，复述只会多花 token，还容易和技能的最新版本不一致。模板见 `模板_简短提示词.md`。上面三份 2026-11-02 的提示词包保留作参考：公司检查清单（"核实："条目）这类技能里没有的任务信息，仍可作为"本次特殊要求"附上。
