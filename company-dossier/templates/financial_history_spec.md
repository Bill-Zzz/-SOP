# 历史数据 Excel 规格（每家公司一份）

目的：让用户能自己分析一家公司的全部历史数据，并作为公司档案报告所有数字的唯一底座。

**样板**：用户的 AMZN 工作簿，Google Sheets《AMZN 历史数据与图表》，文件 ID `1berhHOr675gohS4zlRpg6LMWuVD2Bqk7Ey9lUHX2qr0`。工作表结构、列顺序、图表集中在"图表总览"并随年份筛选更新的做法，完全仿照样板。**不做季度全表**：只做年度全史 + 近 12 个季度。

## 总则
- 一家公司一个 `.xlsx`，文件名 `YYYYMMDD_<代码>_历史数据_v<序号>_<AI名>.xlsx`。
- 年度时间跨度能多长就多长；1995 年之前的数据可选择性省略，有关键转折的老牌公司放宽到更早。季度只取最近 12 个季度。
- 三表数据不从 SEC 逐份取。优先级：本地数据导出（富途三表长表、底稿、日线；位置与结构见 SKILL.md"来源分工"，Drive 路径 `计算机 › 我的 Mac › futu_export`）→ 券商模型里的历史表 → 公司 IR 财务数据包。SEC 文件只用于分部附注、MD&A、融资与收购公告。
- 金额统一为亿美元（或原币，表头注明）；占比与同比用 %；空白表示未披露，不等于 0；新旧分类不可相加时分列并注明。
- 每张表最后一列是来源 ID；"来源"表登记 ID → 文件、网址、定位。
- 用 openpyxl 新建（新建可写图表）；修改已有文件走 `../../scripts/xlsx_patch.py` → `lo_recalc.sh`，不要用 openpyxl 保存已有工作簿。

## 验收
- 年度三表勾稽：毛利 = 营收 − 成本，允许差 0.5%；资产 = 负债 + 权益，允许差 2%。
- 年度衍生指标与年度三表一致。
- 近12季度明细的最新一季 = 导出中最新的报告期，并在"说明"写明期末日。
- 历年营收与业务拆分的"现代分类勾稽差额"列全部填写。
- 市值与估值：年末价 × 股数 与数据提供方市值相差 < 5%。
- 图表总览的全部图表能打开，数据区引用"图表计算"里的公式。
- "说明"写清每张表的口径与缺口。
