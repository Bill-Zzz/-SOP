# 历史数据 Excel 规格（每家公司一份）

目的：让用户能自己分析一家公司的全部历史数据，并作为公司档案报告所有数字的唯一底座。以 AMZN 历史数据表（2026-10）为样板。

## 总则
- 一家公司一个 `.xlsx`，文件名 `YYYYMMDD_<代码>_历史数据_v<序号>_<AI名>.xlsx`。
- 时间跨度能多长就多长；1995 年之前的数据可选择性省略，有关键转折的老牌公司放宽到更早。季度数据有多少取多少。
- 三表数据不从 SEC 逐份取。优先级：本地数据导出（富途三表长表、底稿、日线；位置与结构见 SKILL.md"来源分工"，Drive 路径 `计算机 › 我的 Mac › futu_export`）→ 券商模型里的历史表 → 公司 IR 财务数据包。SEC 文件只用于分部附注、MD&A、融资与收购公告。
- 金额统一为亿美元（或原币，表头注明）；比例用 %；空白表示未披露，不填 0；新旧分类不可相加时分列并注明。
- 每张表最后一列是来源 ID；"来源"表登记 ID → 文件、网址、定位。
- 用 openpyxl 新建（新建可写图表）；修改已有文件走 `../../scripts/xlsx_patch.py` → `lo_recalc.sh`，不要用 openpyxl 保存已有工作簿。

## 第一层：自动生成（脚本从本地导出直接建）
| 工作表 | 内容 | 来源 |
|---|---|---|
| 说明 | 公司、代码、财年口径（FY 对应月份）、币种、覆盖年限（年度 / 季度 / 日线各自起止）、报告类型编号含义、已知缺口、生成日期与脚本版本 | 自动 |
| 年度三表 | 利润表、资产负债表、现金流量表全部科目，年份横排；保留导出的原始科目名，另加标准化中文名称一列（映射表见底稿"科目映射"） | 三表长表 |
| 季度三表 | 同上，季度横排 | 三表长表 |
| 衍生指标 | 逐年：营收增速、毛利率、营业利润率、净利率、研发 / 收入、资本开支 / 收入、折旧 / 收入、经营现金流、FCF、FCF / 净利润、净现金或净负债、商誉 / 总资产、加权股数及其年变化、每股营收 / 每股 FCF、ROIC（写明分子分母）、ROE | 三表计算，公式写在单元格里 |
| 市值与估值 | 逐年年末：收盘价、股数、市值、企业价值、P/E（当年 EPS）、P/S、EV/EBITDA、FCF 收益率、市值 / 营收；另给每年最高与最低市值 | 日线 + 三表 |
| 股价事件 | 单日 ±8% 或滚动 21 日 ±20% 的全部日期：日期、幅度、同日大盘幅度、事件类型（留空由报告填）、备注 | 日线 |
| 图表 | 营收与增速（柱 + 线）；利润率带（毛利 / 营业 / 净利三条线）；现金流去向（经营现金流、资本开支、并购、回购、分红堆叠）；资本开支 vs 经营现金流；市值 vs 营收（双轴）；估值倍数带状图。数据区引用公式，改数据图自动更新 | 前面各表 |
| 缺口 | 导出里没有的科目和年份：研发费用、股权薪酬、回购、分红、折旧摊销、股数等；写"缺什么 / 哪些期间 / 可以从哪补" | 底稿缺口表 |

## 第二层：半自动补充（券商模型、IR 数据包；单独任务填）
| 工作表 | 内容 | 来源优先级 |
|---|---|---|
| 分部营收 | 按公司原披露分类逐年分部营收、占比、同比；分类变更时新旧分列并注明不可相加；勾稽差额列 | 券商首次覆盖报告与模型 → IR 数据包 → 10-K 分部附注 |
| 分部利润 | 分部营业利润与利润率（有披露的） | 同上 |
| 重大融资 | 日期、类型（股 / 债 / 可转债 / 银团）、金额与币种、票息与期限、用途、来源 | 公告、10-K 债务附注、券商报告 |
| 重要收购 | 时间与状态、对象、交易价值 / 净现金 / 终止费分列、后续处置（整合 / 减值 / 出售）、来源 | 公告、10-K、券商报告 |
| IPO 指标 | 上市日期、发行价与股数、募资额、上市时市值与营收、首日表现 | 招股书、当年报道 |
| 指引与实际 | 逐年或逐季：管理层指引区间、实际结果、偏差方向 | 财报电话会、券商报告中的指引追踪 |
| 市值与营收对比 | 可选：与同期参考公司的市值和营收对照（样板里亚马逊对通用电气等） | 市值数据提供方 |

## 验收
- 年度三表：毛利 = 营收 − 成本（允许差 0.5%）；资产 = 负债 + 权益（允许差 2%）；季度加总 ≈ 年度（允许差 0.5%）。
- 股数年变化比值在 0.5–2 之间，超出的标注拆股 / 合股并核对日线复权。
- 市值与估值表：年末价 × 股数 与数据提供方市值相差 < 5%。
- 图表能打开、数据区引用公式。
- "说明"表写清每张表的口径和缺口。
