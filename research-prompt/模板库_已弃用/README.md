# 模板库

- **入库**：用户说"通过"的报告，其任务书存进来，命名 `<类型>_<对象>_YYYYMMDD.md`（如 `全景_某行业_20261104.md`）。存之前删去只对那一次有用的路径与日期，留成占位。
- **参考骨架**：`参考骨架.md` 列四种题型的默认章节，只作参考，不强制；章节以任务书为准。
- **抽模板**：同一新类型第二次出现时，把两份任务书的共同部分抽成模板，存进来。
- 题型特有的内容（章节骨架、追踪线、历史单位、验收特有项）只放在这里的模板里，不进 research-prompt 的 SKILL.md，也不进 research-sop。
