# 简短提示词模板（research-sop 0.11.0 起；0.8.0–0.10.0 的四样模板见 git 历史）

执行 AI 有 Google Drive 权限时，只发下面这一句，把尖括号换成实际内容；不写位置、不复述流程。东西放在哪、怎么命名、状态怎么流转，都在 Drive 根目录《00_先读我》里；方法在 research-sop。没装技能的，先让它读 GitHub Bill-Zzz/-SOP 的 `research-sop/SKILL.md`。

```
你有我 Google Drive 的权限，先读根目录的《00_先读我》，然后：<任务一句话>。方法按 research-sop 0.11.0。
```

只做行业一行示例：`你有我 Google Drive 的权限，先读根目录的《00_先读我》，然后：研究半导体设备行业，AMAT LRCX KLAC TEL ASML 横向比较，只写行业层。方法按 research-sop 0.11.0。`

只做主题一行示例：`你有我 Google Drive 的权限，先读根目录的《00_先读我》，然后：研究 AI 资本开支周期主题，只写主题层。方法按 research-sop 0.11.0。`
