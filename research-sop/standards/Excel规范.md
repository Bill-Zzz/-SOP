## 0a. 执行 AI 必须做到（硬性）

1. 按 `图表总览模板.json` 建首页与"图表计算"，走复制母版或 Sheets API；不经过 openpyxl → xlsx。
2. **每个系列公式外包一层占位**：`=LET(r,<原公式>,IF(COUNT(r)=0,0,r))`。Google 会把整列为空的系列从图表配置里删掉，后面系列的颜色和类型按位置前移（AAPL V1.0/V1.1 的配色漂移即此原因）；整列为空时输出一个 0，系列就一直在，颜色不动。0 在堆叠柱里高度为零、在单点折线里不画，看不见。
3. **图表数据范围从第 3 行表头开始，`headerCount = 1`**；表头为静态短名（与首页标签简称一致，不带单位）。这样图例、悬停提示都显示系列名。
4. **堆叠顺序**：现代业务按收入从大到小在前，旧分类在后，未拆分收入最后；灰色只给最后一项。
5. 首页按 2.1–2.7 排版，四个分区标题带用 2.3b 的区色；首页行数 = 页尾行 + 1，多余行删掉。

| 行 | A | C | E |

| 2 | `起始年份`（10 pt 常规，`#6B7280`） | `结束年份` | `使用方法` |

### 2.3 槽位

第 4 行起全是槽位，一个接一个往下排，槽位之间不留空行（槽位内部已含底部留白）。三种槽位：

| 类型 | 行数 | 高度 | 图 | 用途 |
|---|---|---|---|---|
| W 双宽 | 24 行（576 px） | 一张 1180 × 540 px，锚 C 列 | 结构图、长序列图、≤ 10 系列的多线图 |
| S 单宽并排 | 18 行（432 px） | 左图 590 × 384 锚 C 列；右图 590 × 384 锚 K 列 | 单序列图、≤ 3 系列的图，两张一组 |
| C 局部控件 | 4 行 | 无 | 放在分区标题带之后：`起始年份 / 结束年份 / 显示数据` 或 `起始季 / 结束季`，样式同 2.2 |
| D 分区标题 | 2 行 | 无 | 每个时间口径分区的开头：A:P 合并的浅色色带，行高 28 px，左侧 3 px 区色竖线，区色深字 11 pt 加粗，见 2.3b |

槽位内部布局（r = 槽位首行）：

```
r        A: 块标题                                 C: 图锚点（图从本行开始向右下铺，宽 1180 或 590）
r+1      空
r+2…     A: 勾选框   B: ● 系列名（口径；区间）      ← 一行一个系列，按图例顺序；W 最多 10 行，S 最多 7 行
         空 1 行
         A:B 合并 3 行：口径说明（9 pt 灰）
         A:B 合并 2 行：来源行（9 pt 灰）
…r+23    （W）/ …r+17（S）：剩余行留空，作为与下一槽位的间隔
```

S 类右块的控件用 I:J 列（I 勾选框、J 标签），其余同左块。

点数 > 200 的长序列（日、周、月度长历史）只放 W 槽，并按 research-delivery C3"图表防乱"降频；一行最多两张图，`check_charts.py` 卡住。默认首页用哪些槽位、各放什么图，见 `图表总览模板.json` 的 `slots`；不用的槽位整段删行（连同图）；要加图就在末尾追加一个槽位。

### 2.3a 不重叠的五道锁（硬门槛）

"图之间绝对不重叠"不靠人守规矩，靠下面五条，缺一条不算通过（json `overview.hardGuarantees`）：

| 锁 | 做法 | 挡住什么 |
|---|---|---|
| 1 显式行高 | 建页时用 `updateDimensionProperties` 把首页全部行写死 24 px（第 1 行 32 px）。显式设定后 Google 不再按内容自动调行高，说明文字超长只裁剪不撑高 | 文字把槽位撑得参差、行高被改 |
| 2 坐标只从槽位表算 | `addChart` 的锚点 = 槽位首行、C 列或 K 列，偏移 0；尺寸只有 1180×540 和 590×384 两档；脚本不接受手填坐标。槽位不变量 `行数×24 − 图高 ≥ 24`（双宽余 36，单宽余 48），建图前断言，不满足即中止 | 图放错行、尺寸随意、槽位不够高 |
| 3 保护范围 | `addProtectedRange` 锁整张首页，只放开勾选框与下拉单元格；非所有者不能删行、隐藏行、拖图 | 事后有人删行、隐藏行、拖动图表 |
| 4 标签宽度断言 | 建页脚本对每条 B 列标签按 2.4 的估算公式断言宽度 ≤ B 列宽，超宽即中止，改用简称表里的简称 | 标签长到被图盖住 |
| 5 删多余行 | 建完删除页尾以下所有行，首页行数 = 页尾行 + 1（0a 第 5 条） | 首页拖到上千行 |

路 A 复制母版后要重新执行锁 1 与锁 3，删完不用的槽位后执行锁 5，不依赖复制是否保留。

### 2.3b 按时间口径分区

首页按时间口径分四个区，每区以一条分区色带（D 槽首行：A:P 合并，行高 28 px，`<口径> · <控件说明>`，左侧 3 px 区色竖线，区色深字 11 pt 加粗；色值见下表）开头，同一区内的图共用同一组控件；顺序固定，新图按口径归入对应区末尾，不混放：

| 区 | 标题带 | 控件 | 默认放什么 |
|---|---|---|---|
| — | 色带底 / 字 / 竖线：年度 `#E8EEF8` / `#1E3A6E` / `#1E4FA3`；季度 `#E6F4F0` / `#115E4E` / `#1E8C7A`；单期与事件 `#FBF1E6` / `#7A4A12` / `#F2A35E`；市值 `#F1EDF9` / `#4C2E85` / `#7C4DBF` | | |
| 年度 | 年度 · 随页顶起始、结束年份更新 | 页顶 A3 / C3 | 营收结构（W）、业务占比（W）、总营收 + 同比（S）、业务同比 + 业务营收（S） |
| 季度 | 季度 · 近 12 个季度，用本区起始季、结束季 | 本区 C 槽：起始季 / 结束季，下拉引用"图表计算"季度清单 | 季度营收与同比 + 季度利润率（S） |
| 单期与事件 | 单期与事件 · 不受年份控制 | 无年份控件 | 最新半年各业务 + 已披露净现金收购对价（S） |
| 市值 | 市值 · 用本区起始、结束年份与显示数据 | 本区 C 槽：起始年份 / 结束年份 / 显示数据 | 市值与营收（W） |

默认 13 个槽位的行号见 json `overview.slots`（页顶 3 行 → 年度区 4–89 → 季度区 90–113 → 单期与事件区 114–133 → 市值区 134–163 → 页尾 165）。

### 2.4 块内元素

| 元素 | 规定 |
|---|---|
| 块标题 | `<图名>｜<副题>`，全角竖线；副题写分母、口径或"显示指标 / 显示业务"。11 pt 加粗，文字 `#111827`，无底色 |
| 勾选框 | A 列，数据验证 = 复选框（BOOLEAN），Google 默认样式，列不加底色；默认 TRUE；编辑者共用状态 |
| 系列标签 | B 列。写法固定 `● 简称（起–止）`，如 `● AWS（2013–2025）`、`● 穿戴及其他（2013–2025）`；口径词（原披露、同期占比、可比同比等）**不进标签**，写在本块口径说明里。10 pt 加粗，不换行（CLIP）；**文字颜色 = 该系列在图里的颜色**。**长度硬上限**：估算宽度 = 全角字符数 × 13.5 + 半角字符数 × 7 + 16 ≤ B 列宽 360 px，即简称 ≤ 12 个全角字符；超出的用"说明"页"简称表"里的简称（全名 ｜ 简称 ｜ 颜色），没有就先补简称表再建；建页脚本对每条标签做此断言，超宽即中止。全名可另写进单元格备注。区间写有数据的年份不写创立年；同比系列写可比基期后的年份 |
| 口径说明 | 9 pt、灰 `#6B7280`、自动换行。写分母、口径分段、缺项处理（"缺项不填 0，悬停可查"）、不可相加的组合 |
| 来源行 | `来源：<语义页名>；<指标>，<单位>。` 可带年份：`="来源：营收主表"&CHAR(10)&$A$3&"—"&$C$3&" 全年"`。只写页名与口径，不写研报编号页码 |

### 2.5 图表规格（Sheets API `EmbeddedChart`，完整 JSON 见模板）

| 项目 | 规定 |
|---|---|
| 数据引用 | 横轴 = "图表计算"该块的期间列；每个系列单独一个 sourceRange，**第 3–60 行（含静态表头），`headerCount=1`**，各自写死 color 与 type；系列公式必须带 0a 第 2 条的占位，保证任何时候没有整列为空的系列 |
| 四种原型 | `combo_stacked`：总额折线（`#1F2937`）+ 分部堆叠柱，双宽；`stacked_column`：占比堆叠柱，双宽；`line`：同比、比率折线，单宽或双宽；`column`：单期结构（横轴业务名）、事件金额，单宽 |
| 横轴 | 文本类别；轴标题"年度 / 期间 / 业务" |
| 纵轴 | 轴标题写单位（亿美元、%、倍）。**双轴图左右两条纵轴都必须写轴标题**，写"指标（单位）"，如左"营收（亿美元）"、右"同比（%）"；只有刻度没有标题的不通过 |
| 图例 | 底部；关掉的系列整列为空，图上不画、不画 0；图例项是否保留由 Google 决定，不作要求 |
| 标题 | 写内容与口径，不写图号、不写结论；结论写在报告图注 |
| 字号 | 标题 10、坐标轴 9、图例 9 |
| 网格线 | `#D9D9D9`，置于数据后 |
| 样式 | 白底；**图框 1 px 灰边 `#9CA3AF`**（`updateEmbeddedObjectBorder`），首页每张图都加；无阴影、无三维；折线无标记不平滑；不贴数据标签。纵轴轴线 API 无此开关，不做 |
| 颜色 | 写死在系列上，用 2.6 色板；同一业务全簿同色，标签字色同色 |
| 系列数 | 单序列图 ≤ 3；结构图与多业务同比图 ≤ 10 |
| 缺项 | 公式返回 `""`，图上留空不画 0 |

### 2.6 色板（定稿）

十色，中等饱和，**奇数深、偶数浅**。堆叠顺序规则：业务按收入从大到小领序号 1、2、3…，从底往上堆，相邻两段永远一深一浅；多线图里对照系列用灰色虚线。同一业务在全簿只用一个颜色，"业务 → 颜色"对照登记在"说明"页或来源页。

|---|---|---|---|---|
| 1 | 深 | 藏青 | `#1E4FA3` | 最大业务 / 主要系列 |
| 2 | 浅 | 金 | `#F4C63A` | 预测、待核、强调 |
| 3 | 深 | 青绿 | `#1E8C7A` | 正向 |
| 4 | 浅 | 杏橙 | `#F2A35E` | 扩展 |
| 5 | 深 | 紫 | `#7C4DBF` | 扩展 |
| 6 | 浅 | 天蓝 | `#7FB5EA` | 扩展 |
| 7 | 深 | 砖红 | `#C83E2E` | 负向 |
| 8 | 浅 | 黄绿 | `#B7CB5A` | 扩展 |
| 9 | 深 | 石板蓝 | `#3F6B9A` | 扩展 |
| 10 | 中 | 灰 | `#9AA3AF` | 对照、基准、未拆分；永远排在系列最后 |
| — | — | 深灰 | `#1F2937` | 总额折线 |

**首页页面色（只适用于"图表总览"这一张；语义页、来源页、图表计算仍按格式规范 Part B，表头 `#1F4E78` 白字不变）**：页面本身不带填充色，只有四条分区色带、图和系列标签有色。主标题与块标题文字 `#111827`；控件标签、分区标题、说明与来源文字 `#6B7280`；控件白底加 `#D1D5DB` 细边框；分隔细线 `#E5E7EB`；不用任何填充色；图内网格线 `#D9D9D9`。本色板替代格式规范第 13 节的三色表（历史 / 预测 / 基准）在图表工作簿中的用法；格式规范第 7 节报告图的固定色板同步改为本表（记入 0.20.0 修订）。

### 2.7 页尾

最后一个槽位之后空 1 行，写：`所有显隐开关、年份与分组选择由编辑者操作，属于共用状态。` 10 pt 灰。

## 3. "图表计算"页规格

### 3.1 布局

| 区 | 位置 | 内容 |
|---|---|---|
| 年份清单 | A3 表头 `年份清单`，A4:A60 | `=SORT(UNIQUE(FILTER(VALUE(数据页!$A$4:$A$200), 数据页!$B$4:$B$200="全年")))`；首页年份下拉引用这一列 |
| 映射表 | 第 1–2 行右侧（CK:CN） | 指标下拉用：`下拉显示 ｜ 原字段键 ｜ 选中项说明 ｜ 现有已填期间` |
| 数据块 | 第 3 行表头、第 4–60 行公式；块横向并排，块间空 1 列 | 一张图一块；第一列期间，之后每列一个系列；列名 = 语义页列名去单位 |

### 3.2 公式模板（`<页>` = 语义页名，`<开关>` = 首页勾选框单元格）

① 期间列（年份轴）
```
=IFERROR(FILTER(<页>!$A$4:$A$200,
   <页>!$B$4:$B$200="全年",
   VALUE(<页>!$A$4:$A$200)>='图表总览'!$A$3,
   VALUE(<页>!$A$4:$A$200)<='图表总览'!$C$3),"")
```
② 开关系列（关 → 整列空；开 → 筛年份，非数值留空）
```
=IF('图表总览'!<开关>,
   IFERROR(FILTER(IF(ISNUMBER(<页>!$T$4:$T$200),<页>!$T$4:$T$200,""),
      <页>!$B$4:$B$200="全年",
      VALUE(<页>!$A$4:$A$200)>='图表总览'!$A$3,
      VALUE(<页>!$A$4:$A$200)<='图表总览'!$C$3),""),
   "")
```
③ 口径窗口（系列只在某几年有效；起止年引用单元格，不写死）
```
=IF('图表总览'!<开关>,
   IFERROR(FILTER(IF((VALUE(年列)>=<窗口起格>)*(VALUE(年列)<=<窗口止格>)*ISNUMBER(值列),值列,""), <①的条件>),""),
   "")
```
④ 显示数据下拉
```
=IF(AND('图表总览'!<开关>,'图表总览'!<显示数据格><>"只看营收"), <②的 FILTER>, "")
```
⑤ 指标下拉（表头换键，INDEX/MATCH 找列）
```
表头：=IFERROR(VLOOKUP(<指标格>,$CK$2:$CN$30,2,FALSE),<指标格>)
数据：=IF('图表总览'!<开关>,
   IFERROR(FILTER(IF(ISNUMBER(INDEX(<页>!$D$4:$AZ$200,0,MATCH($BY$3&"（亿美元）",<页>!$D$3:$AZ$3,0))),
                     INDEX(<页>!$D$4:$AZ$200,0,MATCH($BY$3&"（亿美元）",<页>!$D$3:$AZ$3,0)),""), <①的条件>),""),"")
```
⑥ 可筛选事件页（融资、收购）：`=IF(SUBTOTAL(103,<页>!A4)=0,"",<页>!C4)`
⑦ 单期结构块（横轴业务名）：期间列直接引用语义页业务列；值列用 ② 不加年份条件。

### 3.3 规则

- 不出现 `#VALUE!`、`#REF!`、`#N/A`：FILTER、VLOOKUP、INDEX/MATCH 外套 IFERROR 返回 `""`。
- 范围统一到第 200 行，年份不写死；新一年只需在语义页加行。
- 空白 ≠ 0：只在 ISNUMBER 时取值。
- 数字格式：金额 `#,##0.0`、占比同比 `0.0%`、年份 `0`、倍数 `0.0"x"`。
- 块表头列名与语义页列名一致（去单位括号）；**第 3 行表头必须是静态文字，不得随开关变空**——表头一空，Google 会把该系列从图里抹掉并让后面系列的颜色前移（AAPL V1.0 的配色错位即此原因）。

## 4. 语义页为支撑首页的最低要求

| 项 | 规定 |
|---|---|
| 页顶三行 | 1 主标题（14 pt 加粗）；2 口径一句话；3 列标题（底色 `#1F4E78` 白字，列名含单位全角括号，如 `AWS营收（亿美元）`） |
| 期间列 | A 列文本：全年 `1995`，半年 `2026H1`；B 列"期间口径"：`全年 / 半年` |
| 列组 | 每业务三列：营收、占比、同比，顺序固定；新旧分类并列各成组 |
| 来源 ID | 末列组：来源 ID ｜ 勾稽差额 ｜ 分类与同比说明 |
| 冻结 | 前 3 行、A 列 |
| 字色 | 手输蓝、本表公式黑、跨表绿 |
| 页内图 | 可放，规格同第 2 节；数据同样走"图表计算" |

模板里的语义页叫"数据页"，列布局就是上表；真实工作簿里按内容改名（如"历年营收与业务拆分"）后，"图表计算"里的页名引用跟着改（查找替换一次）。

## 5. 验收

首页不设人工验收表。按本规范与 `图表总览模板.json` 建；建页脚本的断言（2.3a 锁 2 槽位不变量、锁 4 标签宽度）不过即中止，按输出改到过为止；`check_delivery.py` 第 14 项实现后由它卡交付。

## 6. 生成与复制流程

**路 A：复制母版（推荐，不需要写图表代码）**
1. Drive 里维护一份母版 `_母版_图表总览`：首页按模板 `slots` 建好全部槽位与图，"图表计算"建好对应数据块，"数据页"只有表头。母版本身用路 B 建一次。
2. 新工作簿 = Drive 复制母版 → 按存储规范改名。
3. 把语义页数据贴进"数据页"（或把 openpyxl 生成的语义页转换后整页复制进来），改页名，在"图表计算"里查找替换页名。
4. 改首页：主标题代码、使用说明、各块标题与标签文字、口径说明、来源行；不用的槽位整段删行。

**路 B：API 直建**
脚本读 `图表总览模板.json`，依次 `batchUpdate`：建三张表 → 列宽行高 → 页顶区 → 每个槽位（标题、勾选框验证、标签格式、说明合并区）→ "图表计算"公式 → 年份下拉验证 → `addChart`（每槽位一张，按原型 JSON 填入 sheetId 与列号）。所有坐标都从 json 的槽位首行算，不手填。

两条路都不经过 .xlsx。首页上的图导出 PNG 做报告快照时，先把开关调到 ≤ 3 个系列。
