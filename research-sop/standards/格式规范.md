# 美股研究报告与金融模型格式规范

**US Equity Research & Financial Modeling Formatting Standards**  
**版本：V1.20**

> 本仓库采用版本。相对 Bill 提供的原文有四处改动：① 金额、股数等一律用万、亿等中文单位（亿美元、万股），不用 USD millions / billions；② 网格线放在柱子和折线后面，不压在数据上（第 7、13 节）；③ 第 2 节文档结构改为报告外壳：标题 → 一、结论与概述 → 任务书定的各章 → 附：口径与说明，不设一页摘要，卷首不放元信息与口径，取舍、数据缺口、修订说明、来源清单进底稿；并加"写法硬要求"四条（research-sop 0.14.0 起元信息放文末，0.15.0 定外壳与写法硬要求）；④ 第 7 节加四条：图片内部不写图号；图号按出现顺序编、文件名 figN 与图号一致（0.14.0）；图注写成"图 N　结论句"；图下来源行只写数据提供方与口径（0.15.0）。


## 1. 适用范围与原则

本规范分别规定两类文件的格式：

1. **研究报告（Research Report）：Google Docs 格式规范。**
2. **金融模型（Financial Model）：Google Sheets 格式规范。**

两类文件分别使用各自的格式标准，不得将 Google Docs 的页面排版规则套用到 Google Sheets，也不得将金融模型的单元格规则套用到研究报告正文。

整体风格参考华尔街 Equity Research Report 和 Investment Banking Financial Model。

本规范只规定格式、字体、字号、颜色、间距、表格、图表和数字呈现，不规定研究内容、分析方法、章节安排或投资观点。

# Part A — Google Docs：研究报告格式规范

## 2. 页面设置

| 项目 | 固定参数 |
|---|---|
| 页面尺寸 | A4 |
| 页面方向 | 纵向 |
| 上边距 | 2.0 cm |
| 下边距 | 2.0 cm |
| 左边距 | 2.0 cm |
| 右边距 | 2.0 cm |
| 正文排版 | 单栏 |
| 页码 | 页面底部居中 |
| 页眉 | 左侧报告名称，右侧股票代码及报告日期 |

- 使用分页模式。报告标题后放置目录，目录之后进入第一章"一、结论与概述"。
- 文档结构（报告外壳）固定为：报告标题 → 一、结论与概述 → 任务书定的各章 → 附：口径与说明。正文分几章、每章讲什么由任务书定，本规范不定。
- "一、结论与概述"不限篇幅，下设"结论""概述"两个二级标题（或两个加粗段），两样必有：**结论**——我的判断、凭什么、什么信号出现说明判断错了；**概述**——正文每一章讲了什么、主要发现是什么。读者看完这一章就知道全文讲了什么、结论是什么。
- 不设"一页摘要"。卷首不放日期、作者、版本、数据截至、涉及行业 / 公司等元信息，也不放全文口径与"不构成投资建议"等说明，统一放在最后一节"附：口径与说明"。取舍、数据缺口、修订说明、来源清单不进正文，全部进底稿。
- 目录、正文各一级板块、附录分别另起一页。正文二级标题随所属板块连续排版。
- 版本、数据截至放在"附：口径与说明"。单位、财年等口径说明放在相关数据章节开头。图表注释随图表保留，图下来源行只写数据提供方与口径。

### 写法硬要求

1. **正文零出处标注**：正文不出现 [R 编号]、[S 编号]、页码，也不出现"研报库""台账""对账""取证"这类过程用语。数据提供方可以写名字，如 WSTS、公司财报、某券商统计。
2. **正文不写工作过程**：取舍、数据缺口、修订说明、来源清单一律进底稿。
3. **每个数字可追溯**：正文每个数字在底稿 `数字台账.csv` 里有一行，"位置"列写所在章节；交稿前用脚本比对正文数字与台账，结果写进自检。
4. **图**：图号按出现顺序编、文件名与图号一致、图内不写图号（第 7 节）；图注为"图 N　结论句"；图下来源行只写数据提供方与口径，不写研报编号和页码。
- 页脚居中显示当前页码 / 总页数。编辑既有报告时保留正文、数据、图表、链接与批注。

## 3. 字体与字号

| 元素 | 字体 | 字号 | 样式 |
|---|---|---:|---|
| 中文正文 | Noto Sans SC | 10.5 pt | 常规 |
| 英文及数字 | Arial | 10.5 pt | 常规 |
| 一级标题 | Noto Sans SC / Arial | 18 pt | 加粗 |
| 二级标题 | Noto Sans SC / Arial | 14 pt | 加粗 |
| 三级标题 | Noto Sans SC / Arial | 12 pt | 加粗 |
| 图表标题 | Arial | 10 pt | 加粗 |
| 表格表头 | Arial / Noto Sans SC | 10.5 pt | 加粗 |
| 表格正文 | Arial / Noto Sans SC | 10.5 pt | 常规 |
| 表格来源 | Arial / Noto Sans SC | 9 pt | 灰色 |
| 页眉页脚 | Arial | 8 pt | 常规 |

**表格正文必须与普通正文使用相同字号，即 10.5 pt。不得因为表格内容较多、列数较多或页面空间不足而擅自缩小字体。**

### 正文字体一致性

- 正文统一继承文档的标准正文样式。以文档中已确认的标准正文段落为基准；需要设置中英文及数字字体时，在正文样式层统一配置。正文段落和局部文字不得另设冲突的字体。
- 对粘贴、导入和手工改过格式的段落，清除局部字体覆盖并恢复正文样式。保留原有加粗、斜体和链接。标题、表格及注释按各自规则处理。
- 交付前逐段核对正文的实际字体和字号，同时检查样式继承与局部覆盖。用最终 PDF 对照不同章节的正文，发现字体不一致时修正并重新导出复查。

### 标题编号与注释补充

- 正文章节一级编号使用中文大写数字，如「一、」「二、」。二级使用父级编号加本级顺序，如 1.1，三级如 1.1.1。进入新父级时本级重新从 1 开始。目录沿用正文编号。报告名、目录及附录标签使用独立样式。
- 正文二级标题的编号与标题文字之间使用一个全角空格。交付前逐项检查编号间距，并在最终 PDF 中确认数字与标题清晰分隔。
- 表注、图注、就地来源注、口径说明以及「数据与可编辑图表」说明使用 9 pt、灰色 `#666666`，保留原有链接。

## 4. 段落与间距

| 项目 | 固定参数 |
|---|---:|
| 正文行距 | 1.25 倍 |
| 正文段后间距 | 6 pt |
| 一级标题段前 | 16 pt |
| 一级标题段后 | 8 pt |
| 二级标题段前 | 12 pt |
| 二级标题段后 | 6 pt |
| 三级标题段前 | 8 pt |
| 三级标题段后 | 4 pt |
| 标题行距 | 1.0 倍 |

不使用空行代替段落间距，不通过连续回车调整页面布局。

## 5. 标题与正文颜色

| 元素 | 颜色 |
|---|---|
| 一级标题 | `#000000` |
| 二级标题 | `#000000` |
| 三级标题 | `#000000` |
| 正文 | `#000000` |
| 辅助说明 | `#666666` |

不使用其他装饰性标题颜色。

### 目录层级与跳转补充

- 按「研究正文」「附录与资料」分组，列出一级和二级条目。一级条目 10 pt 加粗，二级条目 10 pt 常规、左缩进 18 pt，按父级编号，如 1.1、1.2。一级板块间使用 10 pt 段前距，二级条目段后距 5 pt。
- 一级条目只显示标题。没有二级标题的板块，在目录中增加一个同名二级条目，链接到原一级标题。此条目只用于导航。
- 跳转链接放在条目标题文字上，使用黑色、无下划线。二级页码以灰色显示，用点线连接标题，页码统一靠同一右边线。
- 按各条目实际渲染宽度分配点线，保留页码空间。长标题可缩短目录显示名，正文原题和链接目标保留。条目与页码应同一行。
- 按目录链接目标定位正文标题，以排版完成后导出的 PDF 核对其起始页。写入或更新页码后再次导出。若分页变化，重新核对并更新，直到目录页码与最终 PDF 一致。

## 6. 表格规范

| 项目 | 固定参数 |
|---|---|
| 表头背景 | `#17365D` |
| 表头字体 | 白色 |
| 表头字号 | 10.5 pt，加粗 |
| 正文背景 | 白色 |
| 隔行背景 | 白色 |
| 正文字号 | 10.5 pt |
| 正文行距 | 1.25 倍 |
| 单元格段后间距 | 0 pt |
| 边框颜色 | `#D9D9D9` |
| 边框粗细 | 0.5 pt |
| 单元格内边距 | 4 pt |
| 数字对齐 | 居中 |
| 文本对齐 | 左对齐 |
| 合计行 | 加粗，顶部边框 |

表格正文必须保持 10.5 pt，不允许 AI 自动缩小字号以适应页面。

对于内容较多的表格，优先通过调整列宽、换行、行高或分页解决，不得牺牲正文可读性。

表格标题统一放在表格上方，使用 10 pt 加粗字体。来源及注释统一放在表格下方，使用 9 pt 灰色字体。

### 表格执行补充

- 列宽分配以数据完整呈现为首要原则。先按实际渲染宽度为年份、日期、金额、百分比等数据列预留空间，使完整数值（含正负号、小数点、千分位及百分号）尽量单行显示，再把剩余宽度分配给「当年大事」等叙述列。
- 版心紧张时，优先缩窄叙述列，让文字自然换行、行高随内容增加。保留原文、字号与行距。纵向页仍放不下时，按本节改用横向页或分表。
- 交付前用最终 PDF 逐表确认数据未断行、截断或遮挡，叙述文字完整可读。发现问题先调整列宽，再重新导出复核。
- 表体中的说明性文字使用 0.85 倍行距（85%）。交付前逐项核对行距，并在最终 PDF 中检查多行文字的可读性和跨页显示。

- 表格左右外边框对齐正文版心。同一列在全表等宽，在固定总宽内按内容分配空间。
- 数值、百分比、金额、日期及编号列按最长实际值加左右内边距预留宽度。同类数据列宽尽量接近。长表头或单位可换行，说明列优先分配剩余宽度。
- 表头文字统一为白色 `#FFFFFF`，水平及垂直居中，底色须保证白字清晰可读。指标名下方在同一个表头单元格内软换行，使用全角括号标注实际单位，如「（亿美元）」「（%）」。单位及其括号使用 9 pt 常规字重。禁止增加表格行。逐列核对计量口径，凡单位一致的量化指标必须标注，不得仅在正文或脚注说明。混合单位列按行或数据项标注，保留原数据精度。日期、编号和纯文本列无需计量单位。单位不明时查证来源，禁止猜填，未确认项须在交付前列明。
- 表体底色统一为白色 `#FFFFFF`，包括合计行。表体按列含义和单元格用途对齐。独立数值、比率、日期、编号及结构化评级居中，名称、标签和叙述性文字左对齐。含数字的说明仍按文本左对齐。混合列逐格判断，检查典型值和例外值，表体垂直顶端对齐。
- 文本不限长度，保留段落并自然换行，行高随内容增长。数据应完整呈现。常规页宽不足时，采用横向页或分表，保留表头和关联字段。
- 交付前检查列宽、外框对齐、数据断行、文字裁切和跨页显示。

## 7. 图表规范

图表统一采用白色背景、无边框、无阴影、无三维效果。

固定颜色：

| 颜色 | HEX | 用途 |
|---|---|---|
| 深蓝色 | `#17365D` | 主要数据系列 |
| 浅蓝色 | `#5B9BD5` | 次要数据系列 |
| 灰色 | `#A6A6A6` | 历史对照及辅助系列 |
| 绿色 | `#70AD47` | 正向变化 |
| 红色 | `#C00000` | 负向变化 |
| 橙色 | `#ED7D31` | 预测及情景数据 |

固定设置：

- 图表背景：白色。
- 图表标题：10 pt Arial，加粗，左对齐。
- 图片内部不写图号——标题、子图题、来源行都不出现"图 N"，"图 N"只出现在文档的图注里；图内标题只写结论和数字。
- 图号按正文实际出现顺序编：第一张出现的图是图 1，依次类推；插进报告的图片文件名为 `figN_<描述>.png`，N 与图注的图号一致。
- 图注写成"图 N　结论句"（图号后一个全角空格）。图下来源行只写数据提供方与口径，不写研报编号和页码。
- 坐标轴字体：9 pt Arial。
- 图例：9 pt Arial，底部居中。
- 网格线：`#D9D9D9`，放在柱子和折线后面，不得压在数据上。
- 历史数据：深蓝色。
- 预测数据：橙色。
- 基准线：灰色。

同一报告内所有图表必须使用相同的颜色体系。

## 14. 统一执行要求

1. Google Docs 文件严格执行 Part A。
2. Google Sheets 文件严格执行 Part B。
3. 不得将两类文件的格式规则混用。
4. 不同报告和模型不得自行设计新的字体、颜色和排版体系。
5. 不得使用区间值或自行选择替代参数。
6. 如果 Google Docs 或 Google Sheets 不支持某项格式，使用最接近的可实现设置，并保持其他参数不变。

**最终标准：研究报告采用华尔街 Equity Research Report 的排版风格；金融模型采用 Investment Banking Financial Model 的格式。两者是独立文件、独立规范，分别创建和维护。**

## 15. 全规格审阅流程
审阅仅针对本规范规定的格式与排版。文案措辞、论证、事实、数据准确性及投资结论不在审阅范围内。原文、数据、公式、图表、链接和批注的比对仅用于确认格式修改未造成意外变动。单位、引用和公式检查只核对展示、格式分类及修改前后一致性。

1. 修改前登记适用规范版本、文件类型及范围。将第 1–14 节的每条要求拆成可独立检查的项目。记录条款、检查对象、方法、证据、结果和修正记录。结果使用通过、不通过、未核验或不适用。后两项须注明原因。
2. 修改后重新读取交付文件。按下表检查全部适用对象，样例只用于说明检查方法。可程序化读取的属性逐项比较，视觉项目以最终渲染结果检查。
3. 每项发现的问题先定位到页、章节、表格、工作表或单元格，再修正并复查该项和受影响的其他项。涉及分页、引用、公式或图表时，重新导出或重算后再检查。

### 标题编号审阅

- 先划定正文和附录的实际范围，再按标题层级建立父子关系。封面、目录主标题、目录条目和分组栏头不得计入正文章节计数，即使它们套用了标题样式；"一、结论与概述"是正文第一章，计入编号。
- 一级编号取正文实际章序，二级与三级按直属父级分别从 1 重计。附录使用其独立编号体系。只替换已有的结构编号，保留标题中属于原文的年份、数字和名称。
- 写入后重新读取文档，逐项检查父级前缀、同级序号连续性、旧编号残留和目录链接目标。目录编号与目标正文标题核对，同名导航条目不参与正文计数。
- 发现错号、重复、跳号或链接错位时，先修正再重跑检查。编号全部通过后，再按最终 PDF 复核目录页码。无法通过的项目须列明。


1. 逐表逐列判定为单一单位、混合单位或无需单位。核对所有量化列，包括尚未标注单位的列。依据原始数据、表注或明确口径验证币种、量级及单位。
2. 逐项核对单位与指标同属一个表头单元格，单位位于指标下方，使用全角括号、白字、9 pt 常规字重。核对原表行数及原数据精度。
3. 检查目录二级条目及页码是否同一行，长条目优先缩短目录显示名或调整点线。检查各链接是否指向对应正文标题，并按最终 PDF 逐项复核页码。
4. 如有无法核验的单位、页码或显示问题，在交付时列明对应表格、列或目录项。
