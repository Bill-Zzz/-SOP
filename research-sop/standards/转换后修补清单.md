# 转换后修补清单（Google 文档 / Google 表格）

有 Google 文档、表格连接器的 AI 上传转换后按下表原地修补（改同一文件，不重建，链接不变）；没有连接器的把适用条目列进交付说明请用户补。D1 必做，补好前不算交付。

## 上传

- Drive MCP `create_file` 只适合约 9 KB 以内的 .docx / .xlsx；带图报告与历史数据 xlsx 交用户上传（打开"将上传的文件转换为 Google 文档编辑器格式"）或放进同步文件夹后用 Google 文档 / 表格打开。上传后先核对大小或内容完整。
- 导入报 500：只在上传用的副本里删掉 `word/document.xml` TOC 域指令的 `\n 1-1` 与 `\p "…"` 两个开关再导入；本地成品保留原样；导入后按 D1 补页码。

## 修补

| # | 丢什么 | 怎么补 |
|---|---|---|
| D1 | 目录没有页码（格式规范 C10） | 顺序：上传 → 补页码 → 导出 PDF 核对 → `check_delivery.py` 第 12 项通过（读不到文本时附 `--toc-evidence`）。做法 A：请用户点目录，选带页码的样式。做法 B：`read_doc` 取标题 `headingId` → 导出 PDF 定起始页 → `deleteContentRange` 删原生目录 → `insertText` 写条目（标题「　…　」页码，一级不写页码）→ `updateTextStyle`（`link.headingId`、黑色、无下划线；一级加粗 10 pt，二级 10 pt、页码 #666666）→ `updateParagraphStyle`（二级 `indentStart` 18 pt、`spaceBelow` 5 pt，一级 `spaceAbove` 10 pt）；再导出 PDF，分页变了改页码到一致 |
| D2 | 同段内行距不齐 | 导出 PDF 抽查中英混排正文与表格，同类行基线间距不一致即残留分设字体，按 D3 统一后再导出 |
| D3 | 新插入或旧版文档的字体不是 Noto Sans SC | 对插入范围或全部文字片段发 `updateTextStyle`：`weightedFontFamily.fontFamily` = "Noto Sans SC"，`fields` = "weightedFontFamily"；字号、加粗、颜色不动 |
| S1 | 图表刻度与图例字体变 Roboto | `get_spreadsheet`（`fields: sheets.charts`）读 spec → `spec.fontName` = "Noto Sans SC" → `updateChartSpec` 写回；刻度与图例字号 API 无字段，请用户在图表编辑器"自定义 → 图表样式"改 |
| S2 | 图表多出浅灰外框（首页图除外，首页按 Excel 规范 2.5） | `updateEmbeddedObjectBorder`：`border.colorStyle.rgbColor` = 白色，`fields` = "colorStyle" |
| S3 | 网格线颜色不是 #D9D9D9 | API 写不了，请用户在图表编辑器"自定义 → 网格线和刻度"设 |
